# MediConnect

AI-Assisted Healthcare & Telemedicine Platform

## Overview

MediConnect is a Django-based healthcare platform designed
to connect patients with medical professionals.

## Core Features

- Doctor discovery and specialty search
- Appointment scheduling
- AI-assisted symptom triage
- Teleconsultation
- Medical records and prescriptions
- Patient reviews and follow-up

## Technology Stack

- Python / Django
- Django REST Framework
- HTML, CSS, JavaScript, Bootstrap
- SQLite for initial development
- scikit-learn (planned)
- Jitsi Meet (planned)

## Development

Create a Python virtual environment, install dependencies,
apply database migrations, and run the Django server.

## Status

Early development. Not intended for clinical use.
